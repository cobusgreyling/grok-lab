Quick start (any app)

Get running in under 60 seconds

1. Get an xAI API key (free tier available)
https://console.x.ai
2. Run any experiment
cd grok-lab/apps/roast-voice
npm install
npm run dev
Open http://localhost:3000. Toggle real voice after pasting your key.
