# voice-lab — grok-lab

The clean reference UI + interaction model for talking to Grok with voice + tools.

Multiple personalities that change the system prompt, tool toggles, transcript, export. Real chat completions when you provide a key (demo mode otherwise).

**The realtime voice WebSocket client is the big TODO** (see root `docs/REALTIME-INTEGRATION.md` and the LiveKit path). This app shows the desired UX and personalities.

See the [live showcase](https://cobusgreyling.github.io/grok-lab/) for all experiments + screenshots.

Intended to be forked as the starting point for any serious Grok voice product.
