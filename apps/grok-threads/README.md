# grok-threads — grok-lab

Grok is disgustingly good at writing X threads that actually get engagement.

This app generates multiple strong variants (real grok-4.3 when you paste a key), lets you preview them exactly as they will appear on X (pixel-perfect cards), and makes copying the thread trivial (full thread or quote-tweet style).

Many people will use this daily and the best threads will get posted (and hopefully link back here).

See root [grok-lab README](../../README.md) and the [live showcase](https://cobusgreyling.github.io/grok-lab/).
