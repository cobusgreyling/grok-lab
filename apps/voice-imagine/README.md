# voice-imagine — grok-lab

Voice-directed iterative image generation using Grok + xAI Imagine API.

The delightful loop: speak a creative direction → Grok (or quick pills) refines the prompt → generates image → keep talking to edit ("more menacing, tiny hat", "in the style of...").

- Real `grok-imagine-image` calls when you paste an xAI key (falls back to placeholder images otherwise).
- Real browser SpeechRecognition for voice refinements (plus clickable quick-refine pills).
- History strip, live prompt, one-click export of prompt+image link.

This is the one people will record 60-second demos of and post. Great for showing natural creative loops with Grok.

See root README and the [showcase](https://cobusgreyling.github.io/grok-lab/) for the other experiments.
